# Architecture decision records

ADR-001 … ADR-014 are summarised in `docs/ARCHITECTURE.md` §14. Every new decision or reversal gets its own
file here: `NNNN-short-title.md`, numbered from 0015. Number 0014 is reserved for the Celeste alignment
record written in Phase 0.

Template:
```
# NNNN — <decision in a few words>
Date: YYYY-MM-DD · Status: proposed | accepted | superseded by NNNN
## Context
What forces the decision (requirement, constraint, finding — link it).
## Decision
What we will do, stated plainly.
## Alternatives considered
Each with the reason it lost.
## Consequences
What gets easier, what gets harder, what we must now test or watch.
## Revisit when
The signal that should reopen this.
```
