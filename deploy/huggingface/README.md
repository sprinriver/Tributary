# Tributary demo

An open-source experiment data platform for drug discovery: register experiments, explore dataset releases,
chart and compare results. Source and docs: https://github.com/sprinriver/Tributary

- **Synthetic data only.** It resets whenever the Space restarts.
- **Sign in** as `scientist` / `scientist` or `viewer` / `viewer`.
- **Open the app in its own tab** (the "⋮ → Embed this Space → Direct URL" link, or `https://<owner>-<space>.hf.space`).
  Sign-in does not work inside the embedded frame.
